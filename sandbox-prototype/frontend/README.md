# 未来家庭 · 离家检查前端

第一轮产品集成，`baseline_apartment`。本地演示页面已实现 3D 空间定位、离家计划、玄关人工核实、独立出门声明和逐项执行回读。仅使用本机模拟数据，没有连接模拟业务服务或真实设备。

## 启动

需要 Node.js 22 或更新版本；本次使用 Node.js 24.15.0。没有第三方依赖安装或构建步骤。

```powershell
Set-Location -LiteralPath 'E:\hzz\work\智能家居交互\frontend'
npm start
```

等价命令为 `node server.mjs`。打开 **http://127.0.0.1:8780/frontend/**。默认只绑定 `127.0.0.1`，按 `Ctrl+C` 停止。如端口已占用，可在同一 PowerShell 中先设置 `$env:PORT = '8781'` 再启动。

这是静态资源服务，读取同一项目下的模型资产及后端静态 JSON；不要只复制 `frontend` 后单独运行，也不要通过 `file://` 打开页面。预览验收结束后已停止本轮测试进程，按上述命令重新启动即可。

## 使用

1. 保持「猫留卧室」，点击「查看离家计划」。客厅灯默认勾选，卧室空调保留。
2. 点击玄关提醒，定位玄关并在右侧「我已确认关闭」或「稍后核实」。两者都不会提交本人出门声明。
3. 点击「确认关灯（1 项）」。默认每约 3 秒接收一条本地模拟响应：对象有效读数先到，随后执行结果确认。此间可切换房间、设备或全屋复位，任务与勾选保留。
4. 查看逐项结果。顶栏「我已出门」需要单独点击；猫仍留卧室。

右上角「演示设置」可选回读顺序 A/B，开启「手动逐步接收回读」后使用「接收下一条模拟响应」逐项观察。B 顺序是：执行确认 → 旧对象读数过期 → 有效关闭读数。设置适用于下一次执行；要重走主线，点「重新开始本地演示」。该按钮会清空本地任务，全屋复位只改变相机和选中。

设备点选、灯罩网格拾取和计划虚线均不改实况。有效对象读数单独驱动状态动画；`execution.status` 只更新任务。所有模拟证据使用样例时间及本地模拟时钟，不当作真实家庭读数。

## 代码与后续数据入口

| 文件 | 职责 |
| --- | --- |
| `index.html`、`styles.css`、`app.js` | 双栏产品界面、任务步骤、文字详情、演示设置与操作反馈 |
| `scene.js` | 产品 3D 容器：加载交付 GLB、按 actual 映射定位、网格拾取、独立选中层及计划层；复用交付相机和动画运行时 |
| `data-model.js` | `ProductStore`：分开存放对象、任务、执行与能源；处理 v0.2 响应投影、历史证据、旧读数及复位代次 |
| `local-gateway.js` | `LocalGateway`：纯内存的计划、人工核实、出门声明、执行受理和分步回读；不调用查看器的 fixture 注入接口 |
| `server.mjs` | 只读静态文件服务器，没有 `/demo/...` 业务路由 |

未来服务适配器应替换 `LocalGateway`，保持页面消费 `ProductStore` 的方式。核心入口是：

```js
store.applyResponse({ http_status, body }, {
  kind,        // snapshot / task / objects / energy / reset
  taskId,      // 响应未带 task_id 时，使用已知请求关联
  executionId, // 响应未带 execution_id 时，使用已知请求关联
  generation   // 发出请求时的 store.generation，丢弃复位前的迟到响应
});
```

- `snapshot`：对象全量替换；未绑定任务的基线查询不会清空现有任务。
- `objects` / 混合响应：仅投影 `{template_id, objects}` 给交付状态库。计划、人工记录和执行按对应任务更新，能源按自身范围更新。
- `task`：计划与选中集属于任务；执行按执行 ID 和条目 ID 合并。成功确认不会合成对象读数；对象 `off` 也不会自行确认任务。
- `energy`：只更新能源信息，不覆盖离家任务和执行。
- `reset`：仅显式演示复位入口使用；旧代次响应不再应用。

正式接服务前仍需双方独立验收，并确定路由、会话标识、有效期与轮询策略、错误与重试响应。当前页面的 409 复核引导、超时重试、部分失败操作和能源计划流程尚未作为完整产品流程交付；本轮完成四项优先验收链路。不要把本地自动回读的 3 秒节奏当作服务超时约定。
